# 豆包 Seedance 提示词

模型版本参数以 [../config/model-limits.yaml](../config/model-limits.yaml) 为准；本文件只写编译策略，不复制上限副本。

## Seedance 2.0

公式：

```text
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

编写顺序：

1. 锁定“谁在干什么”：主体身份、服装、年龄感、核心动作、手部与眼神细节。
2. 交代“在哪、什么氛围”：地点、时间、天气、关键道具、光源方向和色调。
3. 写“怎么拍”：景别、机位、推拉摇移、手持/固定/航拍/微距。
4. 用视觉风格、画质和约束条件收紧。

要求：

- 单条提示词聚焦一个动作段或一个镜头，避免多个不可同时完成的主体动作。
- 约束写清画幅、时长、镜头数量、人物一致性、禁止字幕水印。

模板：

```text
[画幅与时长] 9:16，5秒。
[主体动作] 一位穿米白风衣的年轻女性站在老城巷口，左手攥着半张车票，右手缓慢抚平额前碎发，眼神从期待转为迟疑。
[场景环境] 黄昏的老城窄巷，青石板潮湿，远处是暖黄路灯和斑驳砖墙。
[光影色调] 黄金时刻低角度逆光勾出发丝，砖墙反射暖橙补光，背景轻微过曝。
[镜头运镜] 中近景，手持微晃，2秒缓慢推镜到面部特写。
[视觉风格] 写实旅行Vlog，胶片颗粒，自然色彩。
[画质] 8K，细节锐利，浅景深。
[约束] 单人单场景，人物一致，无字幕，无水印。
```

## Seedance 2.5

2.5与2.0使用相同公式和顺序；单段时长、参考素材上限以YAML为准。

策略：

- 短镜头仍然精简聚焦，不因支持长段就塞满动作。
- 超过8-10秒或多场景叙事时，按时间块写动作，例如`[0-5s]`、`[6-12s]`，每块只保留一个核心动作和一个镜头目标。
- 需要保持人物、服装、车辆、空间一致时，明确列出参考素材并写明用途。
- 复杂剪辑、转场、延长段落时，把编辑意图写成可执行指令：第几秒转场、延长哪段动作、保持哪个镜头速度。
