# 多模型提示词编译

本文件是第3步“视频生成提示词”的编译核心。只保留共享边界、导演台、修正注入、输出格式和编译前检查；模型细则、角色卡、拆段规则与风格权重按下方路由条件加载，不命中禁止读取。

## 硬边界

- 不调用任何生视频API；只输出提示词，用户手动在即梦、可灵、Sora等工具中生成。
- 第3步由`模型=`参数控制输出：
  - 默认`模型=seedance`：只输出豆包 Seedance 2.5 提示词，1个代码块。
  - `模型=seedance2.0`：只输出豆包 Seedance 2.0 提示词，1个代码块。
  - `模型=hailuo`：只输出 MiniMax Hailuo 3 提示词，1个代码块。
  - `模型=全部`：输出三套提示词，3个代码块。
- 未命中模型细则时，默认 Seedance 2.5 按`model-seedance.md`的2.5节执行；用户指定其他模型时先读取对应切片。
- 画幅固定默认9:16，仅用户明确要求时输出16:9。
- 代码块要便于一键复制，不放额外说明性段落；模型名放在代码块前的标题中。

## 通用导演台模式

导演台的核心不是堆“电影感、高级感”，而是写出可观察的动作、可拍摄的环境和有原因的镜头。

- 写“谁在做什么”，不写“谁有什么情绪”。情绪必须由微表情、手部动作、身体姿态、道具动作外化。
- 镜头运动要有叙事原因：推近是强调反应，跟随是表现紧迫，拉远是暴露处境，航拍是建立地理关系。
- 环境要写光源、天气、时间、材质和色温，不写抽象氛围。
- 声音只写可听到的对象与节奏，不写空泛情绪。

反例：

```text
一个女人读信，很悲伤，很有电影感。
```

正例：

```text
中近景，平视；她放下信，双手停住，一次缓慢推镜靠近；窗边的柔光让她的脸保持素净；现场几乎无声，只留下椅子轻微摩擦声。
```

## 上轮修正注入（@复盘联动）

用户使用`@复盘`后，下一轮生成的每段提示词必须在`[约束]`字段之前追加一行：

```text
[上轮修正] 根据用户反馈注入的修正词，例如：高光、光线充足、面部特征锁定。
```

修正词来源见 SKILL.md 的`@复盘`映射表。修正词在后续每轮持续保留，直到用户输入`@复盘 满意`或明确说“取消修正”后才移除。同一问题累计修正3次仍无效时，建议用户更换镜头方案而不是继续堆修正词。

## 输出格式

第3步按用户指定的`模型=`输出对应代码块。默认和`模型=seedance`只输出“豆包 Seedance 2.5”；`模型=全部`按 Seedance 2.0、Seedance 2.5、MiniMax Hailuo 3 顺序输出。

每个代码块前用一行标题标注模型与分段；代码块首行保留`[固定叙事链]`，随后按所选模型切片的模板输出。

编译前检查：

- 输出代码块数量是否与`模型=`一致，默认是否没有额外输出另两个模型？
- 是否覆盖主体、动作、环境、光影、镜头、画质、约束？
- 画幅是否按用户指定或默认9:16输出？
- 所选模型的时间码、分段、参考角色、模式要求是否满足？
- 有真人主体时是否注入完整角色卡；超上限时是否使用拆段切片？
- 是否按当前风格强度追加对应负面提示词，且写实段没有奇幻词？
- 8段以上是否同时输出剪辑衔接指导和剪辑时间轴参考表？
- 有没有空洞词？发现“科技感”“高级感”“电影感”单独存在时，必须改成具体画面描述。
