# MiniMax Hailuo 3 提示词

Hailuo 3 支持五种模式，模式清单和参数以 [../config/model-limits.yaml](../config/model-limits.yaml) 为准。

| 模式 | 用法 |
|---|---|
| T2VA | 文生视频，无参考素材。 |
| I2VA | 首帧模式，用图片定义第一帧。 |
| FL2VA | 首尾帧模式，用图片定义首帧和尾帧。 |
| L2VA | 尾帧模式，用图片定义结尾帧。 |
| Ref2VA | 全参考模式，用图片、视频、音频等多类参考控制生成。 |

## 参考角色

- 图片管身份：锁定人物、产品、地点、首尾帧外观。
- 视频管动作：参考运动方式、节奏、幅度和镜头表现。
- 音频管节奏：参考节拍、剪辑点或情绪节奏。

禁止混用参考角色。若没有对应素材，不虚构参考用途。

## 时间码与声音

必须用时间码标注节拍：

```text
[0-3s] 无人机从码头低空升起，逐渐展开港湾全景。
[3-6s] 切中近景，背包客抬手挡光，转头看向街角招牌。
```

如使用结构化声音字段：

- `overall_soundscape` 只描述整体声音环境，不重复对话、演唱或画内音乐。
- `non_diegetic_music` 只写配乐的可拍点、乐器、速度、音色和结构，不写“悲伤”“治愈”“燃”这类抽象情绪词。

## 输出结构示例

```text
模式：T2VA
画幅：9:16
时长：6秒
参考角色：图片=身份；视频=动作；音频=节奏。

[0-2s] 中近景，固定机位；穿蓝色冲锋衣的男性在山脊风口站定，帽绳被风掀起，左手抓紧背包肩带。
[2-4s] 缓慢摇镜跟随他的视线；云层缝隙把金色光斑投在碎石坡上。
[4-6s] 轻微推近，他低头查看地图，手指停在折痕处。
overall_soundscape: 持续风声、碎石摩擦、远处鸟鸣；音量随镜头推进轻微收窄。
non_diegetic_music: 无节拍电子底层，80-90 BPM，合成器长音在4秒轻微抬升。
negative: 模糊，肢体畸变，多余手指，水印，字幕。
```
