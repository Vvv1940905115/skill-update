# 拆段生成规则

仅在目标时长超过模型单段上限时读取。各模型单段上限、参考素材上限从 [../config/model-limits.yaml](../config/model-limits.yaml) 读取，本文件不维护副本。

## 段数公式

```text
段数 = CEILING(目标时长 / 模型单段上限)
```

示例：45秒，若当前模型上限30秒，拆2段；若上限10秒，各拆5段。最后一段可短于上限，但所有段时间戳必须连续。

## 连续性要求

- 每段最后1秒画面必须写清结束状态（人物位置、光线方向、镜头角度），作为下一段开场衔接。
- 人物面部、服装、配饰、光线方向和场景色调跨段必须一致；每段完整注入[CHARACTER_CARD]，有参考素材时同时引用。
- 每段开头标注`[段N/共N段]`，写明本段时间范围，例如`[16-30s]`。
- 音效跨段递进，不允许每段重置为同一音量；配乐节拍跨段延续。
- 固定叙事链跨段分配：前段覆盖现实压力锚点到微缩奇观，中段覆盖触发物穿越到动作证明，末段覆盖收口和现实回声。段数不足3段时按比例分配，不允许省略节点。

## 滑动窗口与分段摘要

每段提示词只携带三个上下文字段，不带入全部历史段落详细提示词：

```text
[故事大纲] 全片叙事链概要，100字以内。
[上一段末尾状态] 人物动作/情绪/画面/光线，50字以内。
[当前段目标] 本段覆盖的叙事节点和核心动作，50字以内。
```

每生成满5段，将前面所有详细提示词压缩为1条100字以内摘要，追加到[故事大纲]末尾，替代原文不再重复输出。

## 尾帧与运镜

每段提示词末尾必须追加：

```text
[尾帧画面描述] 最后1秒的构图、主体位置、光线方向、画面色调，50字以内。
[运镜方向] 本段最后一个镜头的运动方向和速度（例如：缓慢推近面部特写 / 航拍上升拉远 / 固定机位定格）。
```

## 8段以上剪辑指导

拆段数达到8段或以上时，在所有段提示词之后输出：

```text
[剪辑衔接指导]
段1→段2：利用段1尾帧的[构图要素]与段2首帧构图呼应；转场方式：硬切/叠化/动作匹配。
```

衔接方式只选三种：尾帧构图呼应、相似动作匹配、转场词过渡。随后追加时间轴表：

```markdown
[剪辑时间轴参考表]
| 段号 | 预计时间戳 | 关键动作点 | BGM节拍建议 | 衔接/转场 |
|---|---|---|---|---|
| 1 | 00:00-00:10 | 具体动作+叙事节点 | 弱起/80-90 BPM/鼓点在第10秒进入 | 无 |
| 2 | 00:10-00:20 | 具体动作+叙事节点 | 节拍密度提升/重音对应关键动作 | 硬切/动作匹配 |
```

时间戳必须连续、不缺段、不重叠；关键动作点写可观察动作，节拍建议写BPM、重音、乐器进入点或声音切换点。
