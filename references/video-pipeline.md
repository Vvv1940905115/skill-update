# 视频流水线执行手册

本文件是短视频一条龙技能的详细执行规则。用户触发"做一条【类型】，主题是【XXX】"后，按本文件逐节执行。

## 通用能力

### 多身份协作机制

内容定稿前以六个身份依次自查，发现问题当场修改：

1. 编导：叙事结构、节奏。
2. 文案：口语自然度、去AI感、台词可念性。
3. 视觉导演：分镜可执行性、镜头语言连贯、画幅与平台匹配。
4. 爆款短视频导演：前3秒钩子、情绪冲突、完播率设计；分镜脚本和台词必须经此身份过审，不达标退回重写。
5. 运营风控：违禁词、事实核查、平台格式。
6. 视频质量把关人：输出前执行"视频质量自检清单"，总分低于8分重写。

### 去AI感规则

写台词和平台文案时执行：

- 开头3秒给具体的人、事、画面或悬念，不用抽象概念铺垫。
- 删模板词和空泛形容："在这个快节奏的时代""令人惊艳""绝美天花板"（除非语境真实）、"赋能""打造"式公文词一律不用。
- 英文文案避免滥用词：unforgettable、breathtaking、hidden gem、delve、tapestry、game-changer。
- 用具体细节替代形容词：时间、地点、数字、动作。"凌晨4点半的机场"优于"难忘的清晨"。
- 口语短句，允许不完整句。台词念一遍，不像人说话就重写。
- 结尾不硬升华，用动作、反问或下期预告收。
- 全平台不出现机器口吻（"作为AI""为您生成"等）。

### 违禁词审查

输出发布包前全文过一遍，命中即替换：

| 类别 | 示例 | 处理 |
|---|---|---|
| 广告法极限词 | 最、第一、顶级、国家级、独家、全网最低、史无前例 | 改为具体事实或删除 |
| 功效承诺 | 治疗、根治、瘦XX斤、美白、100%有效 | 删除，或改为个人体验表述 |
| 诱导胁迫 | 不点赞就XX、必须转发、无兑现的"点击领奖" | 改为自然互动引导 |
| 敏感内容 | 政治敏感、地域/性别攻击、血腥暴力、危险动作示范细节 | 删除 |
| 未经核实数据 | 价格、政策、签证、交通时效 | 核实，或标【待核实】 |

- 广告片、PV/宣传片按广告法最严格标准执行。
- 海外平台同样审查：无医疗声明、无夸大收益、无误导性 Before/After。
- 抽奖/福利活动必须写清规则和截止时间。
- 平台特有敏感词（如小红书外链导流词、抖音第三方平台词）按各平台规则避让。

### 事实核查

- 价格、营业时间、签证、交通、政策、历史事实：先核查再写；无法联网或查不到时，正文不写死，标注【待核实】。
- 引用数据注明口径和来源。
- 个人经历类提醒用户脱敏：住址、证件号、他人肖像与姓名。

## 全赛道 × 平台池映射规则

所有赛道（旅行Vlog、个人成长Vlog、个人经历、广告片、PV/宣传片、旅行宣传片、FPV）都可映射到平台池，不设赛道白名单；但第5步只输出用户确认的平台。

执行规则：

- 第5步执行“先推荐、再确认、后输出”：先生成一行平台优先级建议，再等待用户确认平台名单；未经确认禁止输出任何平台包，禁止一次性输出全平台。
- 第1步只做首发重点或内容加权，可以从平台池中选出1-3个优先平台；它只影响推荐顺序，不代替用户确认。
- 每个平台按其画幅、语感、标签、SEO关键词、互动方式、链接策略和封面安全区重写，不做一稿多投。
- 只有用户确认 U Lifestyle 时才输出该平台，并在其中标注【规则待核实】。

## 第1步：选题策划

1. 确认赛道类型和主题。用户未指定赛道时，按主题内容自动判断：目的地/路线/花销→旅行Vlog；成长/挑战/方法/前后对比→个人成长Vlog；亲历事件/人生节点→个人经历；产品/品牌/服务→广告片；音乐驱动/视觉奇观→PV/宣传片；为某地做宣传→旅行宣传片；无人机/第一人称/高速穿越→FPV。判断后在选题策划开头简要说明赛道选择和理由；信号模糊时选最强匹配，不停下来等确认。
2. 检索最近7天热点：优先平台热榜（抖音热点、微博热搜、B站热门、小红书热点，海外用TikTok Creative Center、X Trending）。无法联网时向用户要近期观察，或采用常青选题并注明【未核查近期热点】。
3. 输出主选题1个和备选1个，每个含：选题名、切入角度、一句话钩子、首发重点（从平台池中选1-3个优先平台）、形式建议（口播/记录/混剪/剧情），并说明与近期热点的关联、为什么现在发。

### 赛道角度库

| 类型 | 常用切入角度 |
|---|---|
| 旅行Vlog | 目的地反差、花销拆解、路线实测、一次遗憾、本地人才知道 |
| 个人成长Vlog | 变化前后对比、100天挑战、方法拆解、失败复盘 |
| 个人经历 | 时间线叙事、转折点、第一人称独白 |
| 广告片 | 痛点场景开场、产品作为解决方案、品牌情绪收尾 |
| PV/宣传片 | 音乐卡点、视觉奇观、快切节奏、情绪递进 |
| 旅行宣传片 | 宏大空镜+人物细节、目的地气质词贯穿（如"松弛感""野"） |
| FPV | 第一人称视角俯冲/穿越、贴面扫过、穿缝/穿林、追逐跟随、人物追踪、空间揭示 |

### 首发平台加权（只影响重点，不删减平台）

| 类型 | 首发建议 |
|---|---|
| 旅行Vlog | 抖音、小红书、B站、YouTube |
| 个人成长Vlog | 小红书、B站、Instagram |
| 个人经历 | 抖音、视频号、B站 |
| 广告片/PV/宣传片 | B站、微博、YouTube、Facebook |
| 旅行宣传片 | 抖音、Instagram、YouTube、Pinterest |
| FPV | 抖音、B站、YouTube、Instagram |

第5步发布包只覆盖用户确认的平台；首发平台只影响平台优先级建议和时长建议，不自动扩大平台数量。

## 第2步：分镜脚本

固定表格列：镜号 | 时间码 | 画面（含花字） | 台词 | 音效 | 时长 | 钩子与情绪

- 时间码填写每镜的“起点-终点”，格式如 00:00-00:03；相邻镜头必须连续，不重叠、不缺段。
- 情绪曲线填写该镜在整体曲线中的走向，例如“低-高”“压-爆”“峰-落”；不能只写一个名词。
- 情绪目标每镜必填，从好奇/焦虑/共鸣/爽感/期待/紧张等中选择；情绪曲线必须有起伏，禁止连续三镜同一情绪。

### 黄金3秒法则（必须严格执行）

- 第1秒：视觉冲击或悬念抛出。
- 第2-3秒：痛点直击或反常识结论。
- 3秒内留不住人，直接重写脚本，不是微调。
- 【前3秒钩子】列填写开篇第1-3镜的钩子设计；中后段每3-5秒安排一个小钩子或反转，防止中段划走。

### 黄金节奏表（必须严格执行）

| 时间段 | 节拍任务 | 执行要求 | 情绪目标 |
|---|---|---|---|
| 0-3秒 | 钩子 | 用悬念、痛点或反常识直接抓人；第1秒必须有画面冲击或信息缺口，3秒内不留人就重写。 | 好奇/焦虑/紧张 |
| 3-10秒 | 痛点放大或故事背景交代 | 快速给出人物处境、代价、环境证据或冲突源头，不做抽象铺垫。 | 焦虑/共鸣/期待 |
| 10-25秒 | 转折点或核心冲突 | 主体遭遇变化、选择、反差或障碍；此处必须形成情绪峰值。 | 紧张/焦虑/爽感 |
| 25-40秒 | 解决方案或情绪升华 | 给出方法、结果、行动证据或情绪出口，并让画面与台词同步释放压力。 | 爽感/共鸣/释然 |
| 最后5秒 | 金句收尾 + 强互动引导 | 用一句短金句收束，再加具体互动提问，例如“你会怎么选？评论区告诉我”。 | 共鸣/期待 |

- 时间码必须与黄金节奏表对应；如果总时长不是40秒，按同一节拍压缩或延展，但0-3秒钩子、10-25秒峰值段和最后5秒收尾不可缺失。
- 25-40秒段落负责解决方案或情绪升华，最后5秒在这段末尾完成金句收束和强互动引导。
- 每个阶段必须有明确的情绪目标，不许平铺直叙；发现连续三镜同情绪或曲线无起伏时，重写分镜。

### 其他要求

- 总时长建议：抖音/快手/TikTok 30-60秒；小红书30-45秒；B站/YouTube 1-3分钟（如需Shorts，另给30-60秒精简版分镜）。
- 台词一句一行，口语化；花字只标关键词，不写整句。
- 音效写到作用点（例：0-2秒风声+起飞音效；3秒卡点鼓点）。

### 人物追踪往事反差模式

用户要求"跟踪人物运镜""带入生活往事""切入痛点反差"或"用视觉画面音效吸引观众"时，本模式强制启用：

- 叙事结构：现实动作线负责速度和画面推进，生活往事闪回负责痛点，二者至少形成两次光色、声音或空间反差。
- 人物运镜：FPV/无人机/手持跟拍保持1-3米距离，优先拍背影、侧身、脚步、手部、呼吸和衣料反应；不依赖清晰正脸，避免跳脸。
- 痛点写法：用具体生活证据，不写"压力大""很心酸"。可用雨夜办公室、冷掉的外卖、亮起的手机、地铁玻璃、旧楼道、停在锁孔前的钥匙等。
- 反差设计：现实段用开阔地形、自然光、风噪、脚步、溪水；往事段用低照度、冷色调、雨声、键盘、地铁、楼道灯等闷声。每段闪回0.6-2秒，短促进入，快速回到现实。
- 视觉优先：情绪不靠旁白解释，靠人物动作、光色变化、空间开合和声音切换传达；旁白每句不超过15字，全片台词保持克制。
- 提示词要求：现实与往事分别写清楚光源、色温、构图、镜头距离和声音对象；人物外形、服装、泥点、包袋、手表等关键特征重复声明。
- 交付检查：前10秒必须出现一次人物追踪和一次往事/痛点信号；中段至少有一次"现实-往事-现实"反差；结尾必须落到可评论的具体提问。

## 第3步：视频生成提示词

先读取 [multi-model-prompt.md](multi-model-prompt.md) 和 [../templates/by-track/common-variables.md](../templates/by-track/common-variables.md)，再按赛道选用模板：旅行Vlog用 [../templates/by-track/travel-vlog.md](../templates/by-track/travel-vlog.md)；个人成长Vlog用 [../templates/by-track/personal-growth-vlog.md](../templates/by-track/personal-growth-vlog.md)；广告片用 [../templates/by-track/advertising.md](../templates/by-track/advertising.md)；PV/宣传片/旅行宣传片用 [../templates/by-track/promo-pv-travel.md](../templates/by-track/promo-pv-travel.md)。个人经历复用个人成长Vlog模板的叙事节拍，并改成第一人称时间线或转折点写法。第3步由`模型=`参数决定：默认`模型=seedance`只输出豆包 Seedance 2.5，1个可复制代码块；`模型=seedance2.0`只输出 Seedance 2.0；`模型=hailuo`只输出 Hailuo 3；`模型=全部`才输出3个代码块。画幅默认9:16，仅用户明确要求16:9时才输出16:9。

所有模型共用质量基线：

- 每镜满足高质量公式：主体动作（细节到微表情、手部动作） + 镜头语言（推拉摇移、无人机航拍、微距特写、手持跟拍等） + 光影氛围（黄金时刻逆光、赛博朋克霓虹、电影级对比光等具体光效） + 画面质感（8K、虚幻引擎5渲染、胶片感、National Geographic风格等）。
- 用"导演台模式"写：不用"科技感""高级感""大片感"这类空洞词，只写可观察动作、环境证据和有原因的运镜。
- 多镜保持一致性：每镜重复人物外形、服装、场景关键描述，避免跳脸、跳服装和场景断裂。
- 每个画幅末尾加负面提示：模糊、肢体畸变、多余手指、水印字幕、低分辨率。
- 镜头过多时按场景合并，标注对应镜号。
- 默认中文提示词；Hailuo 3 的结构化字段名按其规范写，字段内容默认中文。用户指定外语口播时，台词指令按指定语言写。

## 第4步：封面图提示词

输出两个代码块：竖屏（9:16或按首发平台比例）和横屏16:9。

每套包含：

- 画面主体与场景：与成片关键帧呼应，或比成片更有冲击力。
- 构图与留白：预留标题安全区，避开平台界面遮挡（右侧按钮区、底部文案区）。
- 光影与色调：与成片统一。
- 风格质感：摄影感或海报感，说明与视频风格呼应。
- 大字排版建议：主标题文案、位置、字号感觉。字体由剪辑软件加，提示词只负责留白与氛围。

## 第5步：多平台发布包

触发时机：用户说"剪完了""发布包"，或以其他方式确认剪辑完成。此时读取 [platform-publishing.md](platform-publishing.md)，先输出一行平台优先级建议，再等待用户确认平台名单；确认前不输出任何平台代码块。

## 视频质量自检清单（输出前必做）

每次完成分镜脚本和视频提示词后，以视频质量把关人身份逐题打分：每题0-2分（0=不达标，1=勉强，2=达标），满分10分，总分低于8分必须重写薄弱部分并复评，达标后才输出。

1. 前3秒够不够狠？能留住人吗？
2. 情绪曲线有没有起伏？（平淡平淡平淡=划走）
3. 视频提示词能不能一眼想象出画面？
4. 有没有让人想评论的冲动？
5. 这是同行里前三名的质量吗？

自检在内部完成，不向用户展示过程；第5步发布包的标题、互动话术和预埋评论按 [platform-publishing.md](platform-publishing.md) 的互动升级标准复核。
触发"人物追踪往事反差模式"时，额外检查：人物追踪是否有明确距离和身体部位；往事是否足够具体；现实/往事是否有可听见的声音反差；旁白是否克制；结尾互动是否可回答。

## 输出组织

触发后的回复按以下顺序输出，每步用编号标题：

1. 选题策划
2. 分镜脚本
3. 视频生成提示词
4. 封面图提示词

第5步发布包在用户确认平台名单后输出，只包含确认平台代码块和[自查评分卡]。
