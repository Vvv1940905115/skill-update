# 广告片参考稿模式

广告片、TVC、品牌宣传片和品牌种草片按本文件补充产品/品牌写法；结构以 [track-core.md](track-core.md) 的“B站双参考结构公式”为准。这个模式的目的是把品牌片从“随机创意”变成可复用的爆款结构：现实锚点 -> 穿越/跃迁 -> 奇观递进 -> 产品激活 -> 产品证明/情绪仪式 -> 品牌收口。只复用结构、节奏、镜头功能和转化逻辑，不复刻参考片或用户素材中的人物、文案、品牌和专有内容。

## 输出骨架

用户触发广告片生成时，按以下顺序输出；字段名保留，括号内替换为具体内容。

1. **选题方向**
   - 一段话写清：产品、目标人群、情绪压力源、幻想或创意机制、产品出场方式、记忆句。
   - 如用户提供参考视频、参考图或参考文案，注明灵感来源，但不得照搬专有内容。
2. **选题优势**
   - **爆点机制**：按秒写出前3秒钩子、中段视觉高潮、情绪释放、产品亮相和品牌收口。
   - **人群**：年龄、职业、生活状态、情绪痛点、转化阶段。
   - **依据**：说明参考素材的结构、时长、可复用公式或洞察来源；没有参考素材时写常识洞察或【待核实】。
   - **B站结构链**：现实锚点 -> 穿越/跃迁 -> 奇观递进 -> 产品激活 -> 情绪落点 -> 收口；转化功能按“压力源 -> 情绪出口 -> 突破 -> 产品证明 -> 品牌印记”继续拆解。
   - **产品剧情检验**：把产品移除后，故事是否仍成立？若成立，必须重写，让产品成为完成情绪升级或解决核心冲突的必要载体。
   - **系列延展性**：给出记忆句和2个以上不同压力场景的延展方向。
3. **视频规格**
   - 任务类型、画幅、时长、视觉风格、色调走向、情绪关键词。
   - 投放平台、转化目标、投放方式。
4. **角色列表**
   - 每个人物、产品、道具和象征物单独列出。
   - 人物写年龄、性别、发型、服装、配饰、状态和关键身份锚点。
   - 产品写颜色、材质、轮廓、logo/车标/主视觉位置、可识别细节和禁止变形项。
   - 象征物写与产品的视觉呼应关系，例如比例、线条、颜色、动作特征。
5. **镜头列表**
   - 15秒用4-6镜，30秒用5-8镜，60秒用8-12镜。用户明确指定时长时按节奏调整，但不允许相邻镜头重叠或缺秒。
   - 每镜固定格式：
     - `镜头N-「00:00-00:XX」`
     - `画面：主体、动作、关键道具、景别、机位、运镜、光色、质感。`
     - `文案：无文案或旁白/台词；【音效：具体声音对象和节奏】。`
     - `产品状态：不出现/暗示/首次露出/主画面/名称口播+品牌标志。`
     - `转化功能：钩子/压力释放/选择/突破/产品激活/证明升级/收口。`
6. **背景音乐**
   - 写乐器、节拍、进入点、淡入淡出点和声音层级变化。
   - 可写“全程无BGM，仅用音效驱动”，但必须说明音效如何承担情绪递进。
7. **前3秒钩子**
   - 独立成段，写清第1-3秒的具体视觉、听觉和悬念，不允许只写“引人注意”。
8. **视频生成提示词**
   - 由`模型=`参数决定：默认`模型=seedance`只输出豆包 Seedance 2.5；`模型=seedance2.0`只输出 Seedance 2.0；`模型=hailuo`只输出 MiniMax Hailuo 3；`模型=全部`输出三套。仅用户明确要求16:9时才输出16:9。
   - 每个模型代码块必须覆盖镜头列表中的每一镜，不得只写泛化场景或跳过产品转化镜头。
9. **封面图提示词**
   - 一套，画幅与视频一致；用户明确要求16:9时同步切换。优先选择产品变形、转化瞬间、情绪峰值或产品与压力源反差最强的画面。
10. **发布信息**
   - 封面图选择理由、标题、话题、CTA、评论区预埋、投放建议和系列规划。
   - 这不是第5步平台发布包，只是广告片参考稿必备的发布信息；完整平台包仍按平台确认流程输出。

## 镜头级提示词模板

豆包 Seedance 2.0 / 2.5 可按镜头号分段；2.5和 Hailuo 3 长段必须用时间码分块。

```text
[镜头1 00:00-00:04]
[画幅与时长] 9:16/16:9，4秒。
[主体动作] 具体人物在压力场景中完成可观察动作；微表情和手部动作写清。
[场景环境] 地点、时间、光源、天气、材质和关键道具。
[光影色调] 光源方向、色温、明暗对比、反射或渐变方式。
[镜头运镜] 景别、机位、运动方向、运动速度和运动原因。
[视觉风格] 写实广告/3D与实景结合/CG质感等可执行风格。
[画质] 8K，细节锐利，浅景深等。
[文案/音效] 台词或旁白；具体环境声、动作声、产品声和节拍进入点。
[约束] 人物/产品一致性、时长、单镜单动作、无字幕水印、负面提示。
```

产品镜头必须额外写入：

- 产品颜色、材质、轮廓、关键细节、logo/车标位置。
- 产品表面反光、镜头角度和背景对比。
- 产品动作是否符合事实，不虚构功能或性能。
- 品牌收口镜头的构图留白与产品识别细节。

## 质量红线

- 前3秒必须有具体人物、压力证据或反常画面；第1秒不能是空镜铺陈。
- 每个镜头的秒数连续，不缺段、不重叠；30秒片至少安排一个中段视觉高潮和一个产品激活点。
- 产品必须解决故事冲突或完成情绪升级；不能只做结尾硬广。
- 情绪不靠形容词解释，必须由动作、光色、空间变化和声音承担。
- 广告法极限词、功效承诺、最高级式表述和未核实性能数据一律删除或改成可核实事实。
- 输出前检查每个模型提示词是否能还原镜头列表；发现镜头缺失、产品状态不清或转化链断裂时重写。
