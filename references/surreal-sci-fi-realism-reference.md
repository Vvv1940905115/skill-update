# 超现实科幻 + 电影级写实参考

## 触发条件

用户提到“超现实”“科幻感”“世界异变”“现实被改写”“AI 展示片”“城市奇观”“电影级写实”或要求把日常场景转成奇幻景观时，必须使用本文件。所有赛道都可在不改变转化目标的前提下调用这套风格。

## 核心风格

- **超现实科幻**：现实世界被未知规则、高维力量或系统化异变改写，异象要有因果，不是随机奇观。
- **电影级写实**：光源、材质、反射、景深、尘粒、水汽、车漆、砖石、皮肤和布料都要有可信物理细节。
- **世界改写**：城市建筑、道路、树木、交通工具或日常物件在局部被重构，允许出现乐高、纸牌、冰块、几何体、晶格、玻璃等新形态。
- **日常反差**：用普通动作承载异变，例如老人浇花、鸽子起飞、纸飞机、交通灯、收音机、便利店门、地铁闸机等。
- **修复与回收**：异变不是终局，最后必须有“规则修复、高维干预、时间回滚、城市复原”或“现实回声”。

## 叙事公式

```text
日常锚点：先拍一个可信的生活动作、地点或压力源。
异变触发：给一个可见、可听的触发物，例如灯光闪烁、信号跳变、雨滴停住、铃声变形、玻璃反光异常。
局部改写：让一个熟悉物件先发生变化，再扩散到街区、建筑、交通工具或人群。
人类反应：普通人不是旁观者，要有停步、抬头、后退、伸手、护住物品、对视或奔跑等具体动作。
规则揭示：用镜头关系解释新世界的逻辑，尺度、时间、重力、材质或声音规则至少改变一项。
修复/回收：异象被高维力量、系统、时间回滚或主角行动修复，或转入品牌/主题收口。
现实回声：留下一个可识别的日常细节、标题安全区、品牌识别或行动引导。
```

## 镜头语言

- 用航拍建立城市地理关系，再快速下降到人物或物件。
- 用长镜头/穿梭运镜串联异变扩散，镜头运动要有原因。
- 用跟拍、手持、POV、贴面穿越和环绕制造沉浸感。
- 每次世界改写前后至少保留一个稳定锚点，让观众知道空间和时间在哪里。
- 特写负责材质和触发物，全景负责规模，人物反应负责情绪。

## 音画同步

- 前 3 秒必须有一个听觉异常：铃声变形、电流声、低频震动、环境音骤停或节奏错位。
- 视觉异变和音效节拍要对位，建筑生长、玻璃碎裂、物体重构要有清晰音点。
- 修复段用环境声回填或低频下沉，让“世界复原”可听见。

## 提示词模板

```text
[风格] 超现实科幻 + 电影级写实，写实光影与可信材质。
[日常锚点] 具体人物、动作、地点、时间、光源。
[世界改写] 哪个物件/建筑/街区被改写；新形态、材质、尺度和物理规则。
[触发物] 灯光、声音、反光、按钮、雨滴、风、信号、手部动作等。
[人物反应] 停步、抬头、后退、护住物品、伸手、奔跑、对视等可拍摄动作。
[镜头运镜] 航拍/穿梭/跟拍/POV/环绕/长镜头，写清运动方向和叙事原因。
[光影质感] 写实光源方向、色温、反射、景深、颗粒、体积光。
[音画同步] 异变音点、修复音点、环境声变化、节拍进入点。
[修复/回收] 时间回滚、系统复原、高维干预或现实回声。
[约束] 不卡通化、不空洞堆奇观、不跳空间规则，无字幕水印，负面提示。
```

## 质量红线

- 异象必须有触发物和规则，不能只做随机猎奇。
- 生活物件必须有真实质感，不能全部卡通化。
- 每段异变都要有人类反应，不能只有空景。
- 修复/收口必须存在，不能让故事停在混乱里。
- 不得照抄具体品牌、人物、文案和专有镜头，只复用结构与风格。
