# 赛道共享骨架（track-core）

本文件是所有赛道每次常规生成、链接复刻和极简模式必读的唯一共享骨架。赛道专属替换规则一律在 [references/tracks/](tracks/) 对应切片中，本文件不包含赛道差异；未命中赛道切片时禁止读取其他赛道文件。溯源基准：固定叙事链来源为 [local-racing-dream-reference.md](local-racing-dream-reference.md)，仅当需要溯源或校准叙事链时读取，常规生成不读。

## 固定叙事链：办公桌上的赛车梦公式

所有赛道每次输出视频生成提示词前都必须强制套用以下固定叙事链；口播带货、种草等非奇幻赛道只允许替换节点内容，不允许删掉节点（用户指定`节点=口播`或触发极简模式时，按对应压缩映射执行）。

```text
现实压力锚点：先写一个具体、可信、能看见压力或欲望的场景。
幻想种子：用一个可识别的小型道具、标志物或念头把主角的渴望具体化。
微缩奇观：把道具或念头放进一个可拍摄的微观世界、身体动作、地形竞速或场景跃迁里；非奇幻赛道可写成具象奇观。
触发物穿越：用一个看得见的触发物把幻想推入真实主体或目标世界；非奇幻赛道可写成场景跃迁、注意力切换、产品介入或使用方式切换。
主体登场：产品、地点、方法、核心事件或主张以真实尺度出现。
动作证明：让主体完成一次可观察的关键动作，不能用形容词代替能力。
收口：留下主视觉、记忆句、标题安全区、品牌识别或行动引导。
现实回声：回到现实锚点，或停在品牌/行动安全区，证明情绪转化已经完成。
```

极简模式（条件短路）：总时长不超过15秒且叙事密度为低且主题为单镜头产品特写或单场景展示时，固定叙事链压缩为3节点：

```text
【吸引注意】= 现实压力锚点+幻想种子合并为一个视觉钩子。
【核心展示】= 微缩奇观+触发物穿越+主体登场+动作证明合并为一次可观察的产品关键动作。
【行动呼吁】= 收口+现实回声合并为一句行动引导或品牌定格。
```

`节点=口播`压缩：固定叙事链压缩为【钩子】+【痛点/价值证明】+【行动呼吁】三节点，仅保留钩子、痛点与行动呼吁；映射方式与极简模式相同，由SKILL.md的节点跳过参数控制。

叙事密度参数：用户可用`叙事密度=低/中/高`指定，未指定时按主题自动判断（单产品展示/单一情绪为低，多事件/多转折为高）。

## 风格基线：超现实科幻 + 电影级写实

风格强度滑块（0-100）。用户可用`风格强度=N`指定，也可继续用`视频风格=`参数（等价映射见下）：

- `风格强度=0`（等价`视频风格=纯写实`）：关闭超现实科幻滤镜，只保留电影级写实的光影、材质、景深和人物反应；提示词中不出现世界改写、异变、高维力量等科幻词；`[世界改写]`字段替换为`[环境细节]`，`[修复/回收]`字段替换为`[情绪收口]`。
- `风格强度=100`（等价`视频风格=超现实科幻`）：按 [surreal-sci-fi-realism-reference.md](surreal-sci-fi-realism-reference.md) 执行，现实锚点可信、异变有触发物和规则、物件可改写但光影写实、最后必须有修复/回收。
- `风格强度=21-70`（混合模式）：写实和奇幻按比例共存，写实部分用纪实词汇、奇幻部分用超现实词汇，同一镜头内不混用；权重分配详见 [style-weight.md](style-weight.md)。
- 用户主题为乡村生活记录、纯自然纪实、日常人物追踪等无奇幻元素内容且未指定强度时，自动设为0并告知用户。默认强度按快捷预设或赛道默认决定。

超现实科幻模式下，视频生成提示词里至少要出现以下字段：`[风格]`、`[日常锚点]`、`[世界改写]`、`[触发物]`、`[人物反应]`、`[修复/回收]`。前3秒必须有一个视觉或听觉异常；每次改写都要保留一个稳定空间锚点，不能只堆奇观。纯写实模式下，`[世界改写]`和`[修复/回收]`分别替换为`[环境细节]`和`[情绪收口]`，前3秒异常改为真实视觉冲击或悬念。

## B站双参考结构公式

所有赛道的视频生成提示词都必须先过这个公式。它是B站两支汽车广告参考片抽象出来的通用结构，不是汽车广告专用模板。每条片必须保留"现实锚点 -> 穿越/跃迁 -> 奇观递进 -> 主体激活 -> 情绪落点 -> 收口"的骨架，只按赛道替换主体和奇观内容；赛道替换公式见对应 [references/tracks/](tracks/) 切片。

```text
现实锚点：先给一个具体、可信、可观察的起点。人物被困/渴望/出发/使用旧方案，环境必须留下压力或欲望证据。
穿越/跃迁：用一个可看见的触发物把现实推入幻想、目的地、方法、记忆、产品体验或竞争场。穿越前后要有规则变化：尺度、空间、速度、时间、光线或身份至少改变一项。
奇观递进：进入新规则后，用2-4个更大或更近的画面推进。前一景是压力/入口，后一景是能力/空间/关系展开，不允许堆无目标空镜。
主体激活：让产品、地点、人物成长、核心事件或主张在新世界里完成关键动作。这里必须写出可识别细节和事实内能力，不能只靠氛围。
情绪仪式：让主体、人物和环境完成一次可拍摄的情绪同步：对视、停顿、庆典、握手、抵达、开合、点火、回头、松手或人群反应。
现实回声：最后回到现实锚点，或停在品牌/行动安全区。收口必须能证明这条片已经完成转化，而不是画面突然结束。
```

两支参考片的功能映射：

1. **幻想世界穿越参考**：现实驾驶 -> 异世界穿越 -> 幻想奇观 -> 产品动力与细节 -> 与新世界角色互动 -> 庆典/篝火/烟花 -> 品牌收口。可迁移给广告片、TVC、PV/PVC、宣传片和FPV。
2. **日常尺度跃迁参考**：教室/日常受限 -> 小型幻想物 -> 玩具放大为真实尺度 -> 障碍竞速 -> 冲出幻想进入现实 -> 产品性能与外观激活 -> 人物望向窗外 -> 情绪收口。可迁移给个人成长、个人经历、往事、口播带货和种草。

注意：广告、口播带货和种草可以把"穿越"做得非常克制，不能为了奇观虚构功能；口播带货尤其要用可信证据承接穿越，不要让产品只在幻想里悬浮。

## 输出骨架

按以下顺序输出；字段名保留，括号内替换为具体内容。

1. **选题方向**
   - 一段话写清：主体、目标人群、压力源/欲望/悬念、推进机制、情绪或产品落点、记忆句。
   - 如用户提供参考视频、参考图或参考文案，注明灵感来源，但不得照搬专有内容。
2. **选题优势**
   - **爆点机制**：按秒写出前3秒钩子、中段视觉/叙事高潮、情绪释放、主体落点和收口。
   - **固定叙事链**：按"现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声"写清本片链路；非奇幻赛道只替换节点内容，不删节点。
   - **风格基线**：写清"超现实科幻 + 电影级写实"的世界改写规则、日常反差、触发物、人物反应和修复/回收方式。
   - **B站结构链**：按"现实锚点 -> 穿越/跃迁 -> 奇观递进 -> 主体激活 -> 情绪落点 -> 收口"写清本片链路，并把赛道替换公式落到具体主体上。
   - **人群**：年龄、职业、生活状态、情绪痛点、转化阶段。
   - **依据**：说明参考素材的结构、时长、可复用公式或洞察来源；没有参考素材时写常识洞察或【待核实】。
   - **转化逻辑链**：按赛道替换起点和落点，但必须是一条连续链，不能只是"好看、有共鸣"。
   - **主体剧情检验**：把产品、地点、人物成长或核心事件移除后，故事是否仍成立？若成立，必须重写，让主体成为完成情绪升级或解决核心冲突的必要载体。
   - **系列延展性**：给出记忆句和2个以上延展方向。
3. **视频规格**
   - 任务类型、画幅、时长、视觉风格、色调走向、情绪关键词。
   - 投放平台、转化目标、投放方式。
4. **角色列表**
   - 每个人物、地点、产品、道具和象征物单独列出。
   - 人物写年龄、性别、发型、服装、配饰、状态和关键身份锚点。
   - 产品写颜色、材质、轮廓、logo/主视觉位置、可识别细节和禁止变形项。
   - 地点写时间、天气、光线、空间关系、可识别地标和质感。
5. **镜头列表**
   - 15秒用4-6镜，30秒用5-8镜，60秒用8-12镜。用户明确指定时长时按节奏调整，但不允许相邻镜头重叠或缺秒。
   - 每镜固定格式：
     - `镜头N-「00:00-00:XX」`
     - `画面：主体、动作、关键道具、景别、机位、运镜、光色、质感。`
     - `文案：无文案或旁白/台词；【音效：具体声音对象和节奏】。`
     - `主体状态：不出现/暗示/首次出现/主画面/名称口播+识别细节。`
     - `转化功能：钩子/压力释放/选择/突破/激活/证明/收口。`
   - 每镜写人物时必须锁定面部特征、发型、服装、配饰和关键道具；情绪变化由具体微表情承担，例如呼吸节奏、眉眼、喉结、指节、肩线、嘴角或眼神方向。
   - 镜头列表中必须至少有一镜承担"穿越/跃迁"功能。该镜额外写：
     - `穿越/跃迁：穿越前现实锚点、触发物、穿越后世界规则、主体状态变化、产品或情绪落点。`
   - 如果口播带货或种草没有奇幻穿越，把穿越写成可观察的场景跃迁、注意力切换、产品介入或使用方式切换，不能省略字段。
6. **背景音乐**
   - 写乐器、节拍、进入点、淡入淡出点和声音层级变化；禁止平铺BGM。
   - 按"现实压力锚点、幻想种子、微缩奇观、触发物穿越、主体登场、动作证明、收口、现实回声"逐节点写音量、音色、节拍和环境密度变化。
   - 可写"全程无BGM，仅用音效驱动"，但必须说明每层音效如何在叙事节点承担情绪递进。
7. **前3秒钩子**
   - 独立成段，写清第1-3秒的具体视觉、听觉和悬念，不允许只写"引人注意"。
8. **视频生成提示词**
   - 由`模型=`参数决定输出：默认`模型=seedance`只输出豆包 Seedance 2.5；`模型=seedance2.0`只输出 Seedance 2.0；`模型=hailuo`只输出 MiniMax Hailuo 3；`模型=全部`输出三套。仅用户明确要求16:9时才输出16:9。
   - 每个模型代码块第一行必须写`[固定叙事链] 现实压力锚点=具体内容；幻想种子=具体内容；微缩奇观=具体内容；触发物穿越=具体内容；主体登场=具体内容；动作证明=具体内容；收口=具体内容；现实回声=具体内容。`
   - 每个模型代码块还必须写`[人物连续性]`，锁定面部特征、发型、服装、配饰、肤色和关键道具状态；必要时在`[约束]`里补充汗渍、破损或时间变化。
   - 每个模型代码块必须覆盖镜头列表中的每一镜，不得只写泛化场景或跳过关键转化镜头；音效按固定叙事链节点分层递进，禁止平铺BGM。
9. **封面图提示词**
   - 一套，画幅与视频一致；用户明确要求16:9时同步切换。优先选择变形、反转、峰值、产品与痛点反差或目的地震撼画面。
10. **发布信息**
   - 封面图选择理由、标题、话题、CTA、评论区预埋、投放建议和系列规划。
   - 这不是第5步平台发布包，只是参考稿必备的发布信息；完整平台包仍按“先推荐、再确认、后输出”的平台确认流程输出。

## 镜头级提示词模板

豆包 Seedance 2.0 / 2.5 可按镜头号分段；2.5和 Hailuo 3 长段必须用时间码分块。

```text
[镜头1 00:00-00:04]
[画幅与时长] 9:16/16:9，4秒。
[主体动作] 具体人物在压力/欲望/悬念场景中完成可观察动作；微表情和手部动作写清。
[场景环境] 地点、时间、光源、天气、材质和关键道具。
[光影色调] 光源方向、色温、明暗对比、反射或渐变方式。
[镜头运镜] 景别、机位、运动方向、运动速度和运动原因。
[穿越/跃迁] 现实锚点、触发物、穿越后世界规则、主体状态变化、产品或情绪落点；非穿越镜头可写"延续当前世界规则"。
[视觉风格] 写实/CG/FPV/微距/纪录感等可执行风格。
[画质] 8K，细节锐利，浅景深等。
[文案/音效] 台词或旁白；具体环境声、动作声、产品声和节拍进入点；音量、音色和环境密度必须随固定叙事链变化，禁止平铺BGM。
[人物连续性] 面部特征、发型、服装、配饰、肤色和关键道具状态全程一致。
[约束] 人物/地点/产品一致性、时长、单镜单动作、无字幕水印、负面提示。
```

产品镜头必须额外写入：

- 产品颜色、材质、轮廓、关键细节、logo/主视觉位置。
- 产品表面反光、镜头角度和背景对比。
- 产品动作是否符合事实，不虚构功能或性能。
- 品牌收口镜头的构图留白与产品识别细节。

地点镜头必须额外写入：

- 地点的季节、天气、光线方向、地标/材质/空间纵深。
- 人物与地点的比例关系和视线方向。
- 时间连续性，不出现同一段内日夜、季节、服装突跳。

## 质量红线

- 前3秒必须有具体人物、压力证据、欲望信号或反常画面；第1秒不能是空镜铺陈。
- 每条片必须有明确的穿越/跃迁镜头；穿越前后至少有一项世界规则变化，且主体不能在穿越后消失。若某镜不属于穿越/跃迁，提示词也要说明它如何延续当前世界规则。
- 每个模型提示词必须含`[固定叙事链]`和`[人物连续性]`字段；缺失任一字段视为不合格输出。
- 人物面部、发型、服装、配饰和关键道具必须全程连续；微表情必须跟随叙事情绪变化，不允许同一角色在相邻镜头出现无因突变。
- 音效必须分层递进，跟随固定叙事链节点调整音量、音色、节拍和环境密度；禁止全程平铺BGM。
- 每个镜头的秒数连续，不缺段、不重叠；30秒片至少安排一个中段高潮和一个关键转化点。
- 主体必须解决故事冲突或完成情绪升级；不能只做结尾硬广或空泛升华。
- 情绪不靠形容词解释，必须由动作、光色、空间变化和声音承担。
- 广告法极限词、功效承诺、最高级式表述和未核实数据一律删除或改成可核实事实。
- 输出前检查每个模型提示词是否能还原镜头列表；发现镜头缺失、主体状态不清或转化链断裂时重写。
