# 多平台发布包（分层默认）

本文件只在第5步进入发布包流程时读取。采用“先推荐、再确认、后输出”机制；未经用户明确确认，禁止输出任何平台代码块，禁止一次性输出全平台。

## 分层默认路由

1. 生成前必须先输出一行平台优先级建议，格式为：`[平台优先级建议] 主发XX+XX，辅发XX/XX；出海补充XX/XX。`
2. 紧接着询问：`请确认您需要生成发布包的平台名单（默认为主流3平台：抖音、小红书、视频号）。`
3. 用户明确回复平台列表，或输入`平台=主流3`、`平台=出海`、`平台=全量`等指令后，才生成对应平台代码块。
4. 最终输出只包含用户确认的平台包和[自查评分卡]；禁止输出未确认平台、剧情复述、完整分镜或重复提示词。

确认前不生成发布包；`剪完了`只触发平台确认流程，不等价于确认平台名单。

## 平台池

## 国内

1. **抖音**（竖屏9:16）：标题（前20字有钩子）、标签（3-5个垂类）、话题（2-3个）、封面文案（不超过10字大字）、评论区引导话术。
2. **快手**（竖屏9:16）：标题接地气、有真实感、符合老铁文化；标签、话题、封面文案、评论区互动引导。
3. **小红书**（竖屏3:4或9:16）：标题带emoji、标签、封面文案。
4. **视频号**（竖屏9:16）：生活化标题、社交转发引导、封面文案、互动话术。
5. **微博**（横屏16:9或竖屏）：文案带话题、@引导、转发话术。
6. **B站**（横屏16:9）：标题、简介带时间轴、三连引导。

## 海外

7. **TikTok**（竖屏9:16）：英文/本地化标题，文案含前3秒留人钩子；#fyp #foryou；封面英文大字；评论区英文互动。
8. **Instagram**（Reels竖屏9:16）：标题带emoji；5-10个精准标签；英文封面大字；评论区英文互动。
9. **Facebook**（竖屏9:16或横屏16:9）：英文/本地化文案，带链接引导；少量精准标签；引导分享。
10. **YouTube**（Shorts竖屏9:16 + 常规横屏16:9，代码块内分两部分）：Shorts标题与描述；常规视频SEO标题、描述带时间轴和链接；封面按对应比例说明。
11. **Threads**（竖屏或方形）：轻松口语，英文/本地化，文案不超过500字符；话题标签+互动引导。
12. **X**（横屏16:9或竖屏）：短观点，不超过280字符，英文/本地化；#话题、@引导、转发话术。
13. **Pinterest**（竖屏2:3或9:16）：SEO标题；描述带关键词并引导点击；竖屏大字封面文案。
14. **U Lifestyle**（竖屏优先）：繁体中文；生活化标题；摘要+标签。发布前核实平台规则，并在代码块内标注【规则待核实】。

## 平台算法SEO优化

仅用户确认的平台需要生成。每个平台代码块都必须包含“最佳发布时间”建议，并写清目标时区/用户活跃理由。无法实时核实的热点、BGM、官方活动话题必须标注【待核实】，不得编造具体名称。

- **抖音/快手**：加入最近7天同领域的热门话题词和热门BGM名称；优先让话题词进入标题或首行文案，BGM单独标注为“BGM：xxx（近7天热门）”。
- **小红书**：标题前10个字必须包含核心搜索关键词；标签按“2-3个热门泛标签 + 3个精准标签”输出，并写明关键词与选题的对应关系。
- **B站/微博**：绑定最近3天内的全站热点，并绑定官方活动话题；写明热点与选题的关系，禁止硬蹭和夸大。
- **YouTube/TikTok/Instagram**：标题必须有SEO关键词；描述区必须带高搜索量的英文标签；单独标注“最佳发布时间”，例如“美区早8点”。TikTok继续保留#fyp #foryou。
- **全部平台**：生成“最佳发布时间”建议；国内平台写明活跃时段理由，海外平台必须带目标时区，如“美区早8点”“亚太晚间8点”。

## 互动升级

- 爆款标题公式：悬念+痛点+结果承诺。例：“人均800玩透大理的3个狠招，最后一个本地人都不会主动说”。每个平台的标题都单独过一遍这个公式。
- 互动引导话术：必须是带争议、共鸣或提问的具体话术（例：“如果是你，你会怎么选？评论区告诉我”），不写“欢迎留言”“说说你的看法”这类空话。
- 评论区预埋：每平台预埋2条评论，方向为高赞观点、良性引战（有对立观点但不攻击人）或强共鸣（例：“说真的，第3点我不同意，行程松紧才是关键”），发布后由用户置顶或小号发出。

## 通用要求

- 每个平台代码块必须包含公式化标题、互动引导话术、评论区预埋2条、SEO字段和最佳发布时间。
- 第5步使用紧凑字段行：`标题 / 话题 / 标签 / SEO关键词 / 封面文案 / 互动引导 / 预埋评论2条 / 最佳发布时间`；禁止复述剧情、重复完整分镜或重复提示词。
- 文案默认语言：国内平台简体中文；海外平台英文；用户指定本地化语言时按指定输出；U Lifestyle 固定繁体中文。
- 每个平台按该平台语感单独写，不做复制粘贴式同文。
- 海外文案同样执行违禁词审查和事实核查。
- 最终发布包回复只包含确认平台代码块和[自查评分卡]；U Lifestyle 的规则提示写入该平台代码块内。
