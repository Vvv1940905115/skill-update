# 角色卡片

有真人主体的片子必须在第2步分镜脚本之后输出一次角色卡片，拆段生成时将完整卡片注入每一段提示词。卡片输出后强制附带两行提示：

```text
[建议用户配合ControlNet、FaceID或IP-Adapter等外挂工具使用，效果更佳]
[角色一致性降级策略] 若无法使用外挂或面部仍不稳定，禁止极端面部特写；保持发型、服装、体型、肤色、配饰和光线方向完全一致；优先中景、半身、侧脸、背影或手部动作承担叙事，高风险正面特写只保留在关键情绪点。
```

```text
[CHARACTER_CARD]
性别：
年龄段：
发型：
脸型：
面部特征锁定：五官比例、脸型轮廓、肤色、独特标记（痣/疤痕/胡型），写清具体描述供AI模型和外挂工具双重锁定。
上衣：颜色+材质+款式
裤子：颜色+材质
鞋子：颜色+类型
配饰：
关键道具：
```

规则：

- 每个字段必须填写，没有的写“无”。
- 用户上传人物参考图时，与参考图冲突的字段以参考图为准，并在该字段后标注`[以参考图为准]`。
- 拆段生成时，每段提示词开头完整复制整张卡片，不允许只写“同上一段”。
