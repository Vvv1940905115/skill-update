# 风格强度权重

仅在`风格强度>20`或用户显式指定`风格强度`时读取。`风格强度=0-20`保持纯写实，不加载本表的混合权重。

| 强度区间 | 写实占比 | 奇幻占比 | 影响范围 |
|---|---|---|---|
| 0-20 | 全写实 | 无 | 全片纪实词汇，无世界改写 |
| 21-50 | 70-80% | 20-30% | 仅高潮段出现奇幻元素，锚点和收口保持写实 |
| 51-70 | 40-60% | 40-60% | 中段递进和高潮段有奇幻元素，锚点和收口写实 |
| 71-100 | 0-30% | 70-100% | 全片奇幻风格，按超现实科幻基线执行 |

执行规则：

- 写实部分使用纪实词汇：自然光影、真实材质、胶片颗粒、环境细节、人物微表情。
- 奇幻部分保留超现实词汇：世界改写、异变、触发物穿越、几何变形、晶格、玻璃。
- 同一镜头内写实和奇幻不混用；写实镜头只写纪实词，奇幻镜头只写超现实词。
- 每段`[风格]`字段写明当前强度和本段分配，例如`[风格] 强度30，本段写实（环境细节、自然光影），无奇幻元素`。

## 负面提示词注入

| 强度区间 | 注入位置 | 强制追加内容 |
|---|---|---|
| 0-20 | 每个模型提示词末尾 | `[负面词:奇幻, 魔法, 科幻元素, 世界改写, 异变, 超现实符号, 模糊, 肢体畸变, 多余手指, 水印, 字幕]` |
| 21-50 | 每个模型提示词末尾 | `[负面词:写实锚点段与收口段混入奇幻, 魔法, 科幻元素, 模糊, 肢体畸变, 多余手指, 水印, 字幕]`；已分配的奇幻高潮镜头只保留`[负面词:写实细节被侵蚀, 模糊, 肢体畸变, 水印, 字幕]` |
| 51-70 | 每个模型提示词末尾 | `[负面词:风格漂移, 写实与奇幻同镜混合, 模糊, 肢体畸变, 多余手指, 水印, 字幕]` |
| 71-100 | 每个模型提示词末尾 | `[负面词:写实纪实滤镜压过奇幻主体, 世界规则断裂, 模糊, 肢体畸变, 多余手指, 水印, 字幕]` |

MiniMax Hailuo 3 的负面词写入`negative:`字段；其他模型写入`[负面词:]`字段。负面词必须放在提示词最后，不允许因字数限制删掉。
