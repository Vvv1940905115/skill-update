# 赛道自动推荐路由

本文件只在用户未指定赛道时加载，输出结果必须交给四步确认流的第一步确认；禁止静默路由。

## 候选赛道匹配

用户仅提供主题、未指定赛道时，按主题匹配以下赛道：

1. 人物旅途记录、生活化出行体验 -> 旅行Vlog
2. 人物蜕变、自我突破、成长感悟故事 -> 个人成长Vlog
3. 真人故事、内心情绪、过往回忆叙事 -> 个人经历
4. 产品/服务推广、痛点解决、商业转化向内容 -> 广告片
5. 概念视觉、氛围向、艺术质感短片 -> PV/宣传片
6. 景区/城市宏大风光、地域品牌氛围片 -> 旅行宣传片
7. 第一视角穿梭、沉浸式空间穿越镜头 -> FPV
8. 山野徒步、露营、野外探索、自然户外体验故事 -> 户外纪实

按匹配度排序输出 2-3 个候选并标星首选。用户说“换成XX”时按新赛道重跑第一步。

## 重叠防呆与置信度

用户输入同时命中两条以上赛道信号时，按主题主语判断优先级：

- 人物行程/体验选旅行Vlog
- 产品/品牌选广告片
- 地点/景区选旅行宣传片
- 人物内心/回忆选个人经历
- 空间穿越动作选FPV
- 自然户外环境选户外纪实

仍重叠时，第一行强制打印：`[警告] 检测到多个赛道重叠，已将XX标为首选。如需切换请回复更改。`

置信度公式内联计算，不依赖外部文件：

```text
原始阈值 = 50 + MAX(0, (10 - 输入字数) / 10 * 25) + MIN(15, 歧义词数量 * 5) - MIN(15, 具体名词数量 * 3)
置信度阈值 = MIN(85, MAX(40, 原始阈值))
```

- 歧义词：旅行、风景、生活、故事、记录。
- 具体名词：目的地、景点、城市、品牌、产品名、人物身份、赛道名、时长、画幅、风格强度、模型名。
- 低于阈值时，所有候选赛道全部进入第一步推荐并标注置信度原因。
- 达到阈值时，最高匹配赛道标星置顶，其余作为备选。

两种情况都必须经用户确认后才进入第二步，禁止跳过推荐，禁止静默替换赛道。
