# 户外纪实提示词模板

生成前先读取 [../../references/track-core.md](../../references/track-core.md) 和 [../../references/tracks/outdoor-documentary.md](../../references/tracks/outdoor-documentary.md)，按参考稿结构输出选题、角色、镜头、提示词和发布信息。

强制套用固定叙事链：现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声。每个模型提示词写清`[固定叙事链]`和`[人物连续性]`；人物微表情跟随情绪变化，音效按叙事节点分层递进，禁止平铺BGM。

户外纪实的核心是真实地形、身体反应和天气压力。不美化风险，不虚构极限；必须保留衣物磨损、泥点、汗渍、呼吸节奏、装备状态和地形纹理。穿越点可以是林线、垭口、溪谷转折、雪线、云层裂口或风雪间隙，但必须有可观察的空间变化。

## 开头模板（压力锚点+幻想种子）

```text
[固定叙事链] 现实压力锚点=起点或营地中的天气/地形/体力压力；幻想种子=地图折痕、垭口轮廓、溪谷声、云缝或营地标记；微缩奇观=装备纹理、呼吸、脚步与地貌接触；触发物穿越=进入林线/垭口/溪谷/雪线；主体登场=真实路线、地形或人物目标；动作证明=穿越、脱困、抵达或扎营；收口=终点/营地/下一站/身体痕迹；现实回声=回到出发点状态、装备细节或下一站计划。
[人物连续性] 锁定年龄、面部特征、发型、冲锋衣颜色与磨损、背包、登山杖、手套、帽子、泥点、汗渍和装备位置。
[主体动作] 人物查看地图或抬头看向垭口，呼吸变重，风压让衣摆、帽绳和背包带移动；微表情从判断转为专注。
[场景环境] 山地出发点、营地、碎石坡、林线或溪谷边缘；写清天气、风、雾气、湿度和路面材质。
[镜头语言] 手持跟拍、低角度脚步、侧逆光人物轮廓、抬头视线接远景；保持自然纪实感。
[视觉风格] 写实户外纪录感，高动态范围，自然色彩，轻微颗粒。
[画质] 8K，地形纹理、皮肤细节和装备材质清晰。
[文案/音效] 环境风声、脚步、呼吸、装备摩擦、地图纸声或溪流声；音量随人物动作和地形压力变化，禁止平铺BGM。
[约束] 不虚构危险救援，不夸张天气，无字幕水印。
```

## 中段模板（触发物穿越+主体登场）

```text
[固定叙事链] 现实压力锚点=地形阻隔或天气压制；幻想种子=垭口、云缝、溪谷转折或远处标记；微缩奇观=鞋底抓地、绳索、冰爪、杖尖、水花和风粒；触发物穿越=穿过林线/垭口/溪谷/雪线；主体登场=目的地、核心路线或人物目标真实出现；动作证明=身体完成可观察跨越或推进；收口=前方目标成为主画面；现实回声=身体痕迹和环境余响。
[人物连续性] 与开头同一人物，服装、泥点、汗渍、背包状态、装备位置和面部特征一致。
[主体动作] 人物跨过石缝、抓住岩点、穿越风雪或沿溪谷前进；肩膀起伏、手指收紧、眼神在脚下与前方目标之间切换。
[场景环境] 保留前后一致的山体关系、天气、光线方向和季节；穿越前后写清空间规则变化，如视野、风量、湿度和地形坡度。
[镜头语言] POV/FPV贴地前进、手持跟拍、远景确认比例；穿越瞬间镜头速度和视野发生明确变化。
[视觉风格] 写实户外纪录感，自然运动模糊，不用重CG感。
[画质] 8K，岩面、雪粒、水汽、布料和金属装备细节锐利。
[文案/音效] 风声从闷到开，脚步从碎石变为泥地或雪面，呼吸节奏随坡度变化；穿越点短促增压，禁止平铺BGM。
[约束] 场景连续，不跳天气，不跳季节，无字幕水印。
```

## 高潮模板（动作证明+情绪释放）

```text
[固定叙事链] 现实压力锚点=连续爬升后的体力极限；幻想种子=垭口后的开阔轮廓；微缩奇观=汗珠、呼气、手部抓握和装备振动；触发物穿越=最后一段坡线或岩缝；主体登场=垭口、湖面、营地、山谷或终点标记；动作证明=人物翻越、抵达、放下背包或扎营完成；收口=人物与目的地同框；现实回声=呼吸变慢，视线回到路线或营地。
[人物连续性] 服装破损程度、泥点、汗渍、装备变化必须与中段一致。
[主体动作] 人物完成最后一次跨步后停住，双手撑膝呼吸，随后抬头、松肩、缓慢回头或放下背包；微表情从紧绷转为释放。
[场景环境] 垭口、湖岸、山脊、雪原尽头或营地；远景开阔，近景保留风、雾、水汽和地形纹理。
[镜头语言] 先拍手部与呼吸，再从人物背后升起或缓慢环绕，展开地形全景。
[视觉风格] 电影级写实户外纪录感，高动态范围，自然光。
[画质] 8K，远山层次、皮肤反光和装备细节清晰。
[文案/音效] 风噪降低，呼吸变慢，拉链、背包落地、帐篷布料或营地道具声进入；节拍与环境声逐层变化，禁止平铺BGM。
[约束] 不使用夸张慢动作，不虚构高风险动作，无字幕水印。
```

## 结尾模板（收口+现实回声）

```text
[固定叙事链] 现实压力锚点=抵达后的身体状态；幻想种子=下一站标记或路线记忆；微缩奇观=泥点、磨损、水壶、地图、帐篷或营地灯；触发物穿越=从户外状态回到休息状态；主体登场=终点、营地或下一站目的地；动作证明=人物整理装备、记录位置、喝水或望向远方；收口=标题安全区或下一站提醒；现实回声=身体痕迹和真实环境细节。
[人物连续性] 保持人物、服装、装备和状态连续；如换到营地或返程，写清时间和光线变化。
[主体动作] 人物把背包靠稳，倒出水壶里的石子，或在地图上记下路线；最后抬头看向远处或镜头外侧。
[场景环境] 帐篷前、湖岸、山脊尽头的营地或返程车窗旁；保留自然光和真实生活痕迹。
[镜头语言] 中近景固定或缓慢拉远，最后留标题与下一站安全区。
[视觉风格] 写实户外纪录感，低对比黄昏或清晨光线。
[画质] 8K，装备细节、皮肤纹理和环境层次清晰。
[文案/音效] 帐篷布、拉链、水声、纸页、远处风声和环境余响；音量下降但不突然抽空，禁止平铺BGM。
[约束] 不拍危险姿态，不夸大行程难度，无字幕水印。
```
