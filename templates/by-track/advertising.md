# 广告片提示词模板

广告片、TVC、品牌宣传片、口播带货和品牌种草片必须先读取 [../../references/track-core.md](../../references/track-core.md)，并按当前赛道读取对应切片（广告片/TVC→[../../references/tracks/advertising.md](../../references/tracks/advertising.md)；口播带货/种草→[../../references/tracks/live-commerce.md](../../references/tracks/live-commerce.md)），按“选题方向 -> 选题优势 -> 视频规格 -> 角色列表 -> 镜头列表 -> 背景音乐 -> 前3秒钩子 -> 视频生成提示词 -> 封面图提示词 -> 发布信息”的参考稿结构输出。

强制套用固定叙事链：现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声。每个模型提示词写清`[固定叙事链]`和`[人物连续性]`；人物微表情跟随情绪变化，音效按叙事节点分层递进，禁止平铺BGM。

叙事默认按B站双参考结构公式执行：现实锚点 -> 穿越/跃迁 -> 奇观递进 -> 产品激活 -> 产品证明/情绪仪式 -> 品牌收口。参考稿中的镜头字段必须保留：画面、文案、产品状态、转化功能、穿越/跃迁。视频提示词必须逐镜映射到镜头列表，不允许把镜头表和提示词写成两套不同内容。

## 广告片

### 开头镜头模板

```text
【豆包 Seedance 2.0】
[主体动作] 目标用户在[痛点场景]中动作受阻，眉头收紧，手指反复尝试[失败动作]。
[场景环境] 真实使用环境，如厨房、通勤地铁、办公桌或户外途中。
[光影氛围] 自然光或室内主光，阴影清晰，不让产品提前出镜。
[镜头语言] 特写接中景，特写强调手部失败，中景交代环境限制。
[视觉风格与画质] 写实广告质感，干净色温，8K，浅景深。
[约束] 不夸大痛苦，不出现医疗或功效承诺，9:16或16:9。

【豆包 Seedance 2.5】
2.5可在30秒内完成"痛点-尝试-产品介入"三段；0-5秒必须只有痛点，第6秒后再让产品进入。

【MiniMax Hailuo 3】
模式：T2VA或I2VA。
[0-2s] 特写，手指被包装、键盘、行李或料理过程卡住。
[2-5s] 中景，用户抬头看时间或远处，表情从困惑转为不耐。
overall_soundscape: 环境噪声、摩擦、失败动作的实音。
negative: 模糊，手部畸变，品牌标识错误，水印，字幕。
```

### 中段叙事模板

```text
【豆包 Seedance 2.0】
[主体动作] 产品进入后，目标用户完成一次准确、利落的[核心动作]，手指与产品接触点清晰。
[场景环境] 同一痛点环境开始变有序，关键道具归位。
[光影氛围] 主光从侧后移向正面，产品表面出现可控反光。
[镜头语言] 微距特写展示使用细节，再切中景展示效率提升。
[视觉风格与画质] 商业广告质感，色彩干净，8K，微距清晰。
[约束] 产品标识不变形，功能表现符合事实。

【豆包 Seedance 2.5】
用[0-6s]产品细节、[7-12s]用户操作、[13-18s]环境变化三段。可加入产品多角度图、使用场景图、目标人物图，指定图片只管身份。

【MiniMax Hailuo 3】
模式：T2VA、I2VA或Ref2VA。
[0-3s] 微距，产品接口、材质纹理或握持弧线。
[3-6s] 中近景，用户双手完成操作，动作比开头明显顺畅。
[6-9s] 环境镜头，桌面或空间恢复秩序。
overall_soundscape: 清脆机械声、纸页、脚步、环境声变干净。
non_diegetic_music: 电子脉冲，100 BPM，打击乐在3秒进入。
```

### 高潮/情绪峰值模板

```text
【豆包 Seedance 2.0】
[主体动作] 用户完成关键结果，先把产品轻轻放下，再抬头露出放松表情，肩膀下降。
[场景环境] 从杂乱转向整齐的真实空间，保留生活痕迹。
[光影氛围] 高光干净但不死白，背景有柔和高光斑。
[镜头语言] 缓慢环绕或轻推，产品与用户同框。
[视觉风格与画质] 商业广告质感，高动态范围，8K。
[约束] 不使用夸张特效，不虚构绝对效果。

【豆包 Seedance 2.5】
可将高潮延到8-12秒，并在同一镜头内完成"结果出现-人物反应-产品同框"。用首尾帧控制产品位置和光线。

【MiniMax Hailuo 3】
模式：FL2VA或Ref2VA。
[0-3s] 结果出现，如整齐桌面、打开的行李箱、完成的料理。
[3-6s] 用户看向结果，手指轻触产品。
[6-9s] 缓慢拉远，产品和生活场景同框。
overall_soundscape: 拉链、盖子、环境轻噪声。
non_diegetic_music: 明快打击乐，104 BPM，合成器和声在第4秒进入。
```

### 结尾收束模板

```text
【豆包 Seedance 2.0】
[主体动作] 产品静置在干净背景上，旁边只留一个与用途相关的小道具。
[场景环境] 极简桌面、厨房台面或户外平面上，背景轻微虚化。
[光影氛围] 顶光加侧光，产品边缘有柔和反光。
[镜头语言] 固定特写或缓慢横移，最后停在品牌区留白。
[视觉风格与画质] 商业海报感，8K，色彩准确。
[约束] 留出标题和购买信息安全区，无字幕水印。

【豆包 Seedance 2.5】
结尾可延长到6-10秒：产品定格加一句使用情境，不硬加口号。若加品牌板，保持色调和产品角度一致。

【MiniMax Hailuo 3】
模式：I2VA或T2VA。
[0-3s] 产品特写，光影缓慢过渡。
[3-6s] 镜头轻微横移，背景留白扩大。
[6-8s] 定格在品牌安全区。
overall_soundscape: 轻机械声、纸张、环境底噪。
non_diegetic_music: 极简电子，90 BPM，第6秒淡出。
```
