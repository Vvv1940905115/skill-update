# 宣传片 / PV / 旅行宣传片提示词模板

生成前先读取 [../../references/track-core.md](../../references/track-core.md) 和对应切片（PV/PVC/宣传片→[../../references/tracks/promo.md](../../references/tracks/promo.md)；旅行宣传片→[../../references/tracks/travel-promo.md](../../references/tracks/travel-promo.md)），按参考稿结构输出选题、角色、镜头、提示词和发布信息。PVC触发时按PV/宣传片规则处理。

强制套用固定叙事链：现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声。每个模型提示词写清`[固定叙事链]`和`[人物连续性]`；人物微表情跟随情绪变化，音效按叙事节点分层递进，禁止平铺BGM。

PV/PVC/宣传片的“穿越/跃迁”通常是音乐进入、灯光打开、门/幕布/水面裂开、雾气散开或静场后的第一次运动。提示词必须写清静场锚点、触发物、进入新空间的规则变化和主题释放方式。

## 宣传片 / PV / 旅行宣传片

### 开头镜头模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]或标志物从黑暗或雾气中出现，衣摆、旗帜、水面或尘粒先动。
[场景环境] 山谷、城市天际线、舞台后台或港口，环境有明确地理关系。
[光影氛围] 低照度轮廓光或强逆光，第一秒主体边缘被点亮。
[镜头语言] 缓慢推近或无人机低空升起，先揭示局部，再揭示整体。
[视觉风格与画质] 8K，虚幻引擎5渲染感，高动态范围。
[约束] 9:16或16:9，3-5秒，无字幕水印。

【豆包 Seedance 2.5】
2.5适合做30秒预告：0-5秒只有悬念画面，6-15秒展开空间，16-30秒节奏变快。可用地点、人物、旗帜、车辆等参考素材统一外观。

【MiniMax Hailuo 3】
模式：T2VA、I2VA或Ref2VA。
[0-2s] 微距或低空镜头，水汽、尘粒、旗帜边缘先进入画面。
[2-5s] 无人机升起或缓慢推近，主体轮廓显现。
overall_soundscape: 风、水、金属轻微震动。
non_diegetic_music: 低频电子垫，60 BPM，鼓点不在第一秒抢入。
```

### 中段叙事模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]穿过[场景]中的多个层次，脚步加快，手部与人群、物体或自然元素产生接触。
[场景环境] 城市巷道、古镇长街、山水步道或舞台通道，保留纵深。
[光影氛围] 侧光、霓虹、火光或自然缝隙光交替，主体始终有轮廓。
[镜头语言] 手持跟拍接横移，突出速度和空间转换。
[视觉风格与画质] 8K，高动态范围，色彩分层明显。
[约束] 保持主角外观一致，场景过渡不撕裂。

【豆包 Seedance 2.5】
用多个5-8秒时间块串联不同地点；每块只留一个动作目标。可给每个地点建立参考素材，并明确素材只控制空间和服装。

【MiniMax Hailuo 3】
模式：Ref2VA或T2VA。
[0-3s] 横移跟随，[主角]穿过人群或自然障碍。
[3-6s] 快速摇镜到下一个层次，主体动作不停顿。
[6-9s] 低角度固定，脚步和裙摆/衣摆/车轮掠过画面。
overall_soundscape: 脚步、布料、人群、风。
non_diegetic_music: 电子打击乐，120 BPM，切分音在镜头转换处出现。
```

### 高潮/情绪峰值模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]完成标志性动作，旗帜、滑板、裙摆、火焰或水花同时抬升，视线指向远方。
[场景环境] 最高点、主舞台、港口尽头或城市天台，背景形成对称或放射构图。
[光影氛围] 强逆光加地面反射，主体边缘清晰，背景有体积光。
[镜头语言] 无人机环绕、慢动作推近与全景快切组合。
[视觉风格与画质] 8K，虚幻引擎5渲染感，National Geographic风格或舞台光效。
[约束] 主体不变形，特效有物理感。

【豆包 Seedance 2.5】
可直出8-15秒峰值段：先1-3秒蓄力，4-8秒爆发，9-15秒空间展开。用首尾帧控制起点和终点。

【MiniMax Hailuo 3】
模式：FL2VA、Ref2VA或T2VA。
[0-3s] 慢动作，手、布料或水花先到达高点。
[3-6s] 无人机环绕主体，背景光斑扫过。
[6-9s] 快速拉远，全景形成放射线。
overall_soundscape: 风、火、水、人群欢呼，按动作强度变化。
non_diegetic_music: 弦乐与电子鼓组合，128 BPM，第3秒加重。
```

### 结尾收束模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]背对镜头走向远方，最后一步停住，衣摆回落，标志性元素留在画面一侧。
[场景环境] 海岸线、山谷、城市远景或舞台暗场。
[光影氛围] 落日或舞台余光，主体变成清晰剪影。
[镜头语言] 缓慢拉远或固定，最后保留标题安全区。
[视觉风格与画质] 8K，高动态范围，色彩沉稳。
[约束] 留出口号或标题空间，无字幕水印。

【豆包 Seedance 2.5】
结尾延长到6-10秒，可从人物剪影拉到全景，再加1-2秒标志物定格。保持色彩与高潮段一致。

【MiniMax Hailuo 3】
模式：L2VA或T2VA。
[0-3s] 背影走向纵深，脚步逐渐变慢。
[3-6s] 主体停住，风把衣摆压向一侧。
[6-8s] 缓慢拉远，画面留白。
overall_soundscape: 远风、脚步停止后的环境余响。
non_diegetic_music: 合成器长音，64 BPM，第6秒淡出。
```
