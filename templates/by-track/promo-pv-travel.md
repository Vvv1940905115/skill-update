# PV/PVC/宣传片/旅行宣传片提示词模板

先读取 [../../references/track-core.md](../../references/track-core.md) 和当前赛道切片（PV/PVC/宣传片→[../../references/tracks/promo.md](../../references/tracks/promo.md)；旅行宣传片→[../../references/tracks/travel-promo.md](../../references/tracks/travel-promo.md) 叠加 [travel-promo-patch.md](travel-promo-patch.md)）。提示词按 `模型=` 从 [../../references/model-seedance.md](../../references/model-seedance.md) 或 [../../references/model-hailuo.md](../../references/model-hailuo.md) 加载对应结构。

## 四段骨架

### 开场：现实压力锚点

```text
[固定叙事链] 现实压力锚点=[普通城市/产品/人物状态]；幻想种子=[品牌愿景/目的地吸引力]。
[主体动作] [主角/产品/城市符号]进入[日常场景]，呈现被忽视的美或痛点。
[场景环境] 街道、工位、站台、旧墙、包装或产品细节。
[镜头语言] 小景深开场，前景与人物形成压迫或期待。
[约束] 9:16或16:9，[时长]。
```

### 转折：触发物穿越

```text
[固定叙事链] 触发物穿越=门洞、玻璃、水面、地图折痕、包装开启或镜头旋转。
[主体动作] [主角]从[现实空间]进入[品牌/目的地奇观]。
[场景环境] 穿越前后保留一个连续物证（光、色、道具、影子）。
[镜头语言] 一镜穿越或节奏化硬切，运动方向连续。
```

### 奇观递进

```text
[固定叙事链] 微缩奇观=2-3层递进；动作证明=人物、产品或城市与奇观发生互动。
[主体动作] [主角/产品]完成[标志性动作]。
[场景环境] 地标、自然奇景、抽象装置或光影空间。
[镜头语言] 由局部到全景，再回到可拍摄的人物证据。
```

### 收口

```text
[固定叙事链] 现实回声=奇观留在日常中的变化；收口=品牌/目的地口号或行动呼吁。
[主体动作] [主角]回到[现实场景]，完成[新的选择/动作]。
[镜头语言] 定格、留白或缓慢推近视觉锤。
```
