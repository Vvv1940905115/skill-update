# FPV提示词模板

生成前先读取 [../../references/track-core.md](../../references/track-core.md) 和 [../../references/tracks/fpv.md](../../references/tracks/fpv.md)，按参考稿结构输出选题、角色、镜头、提示词和发布信息。

强制套用固定叙事链：现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声。每个模型提示词写清`[固定叙事链]`和`[人物连续性]`；人物微表情跟随情绪变化，音效按叙事节点分层递进，禁止平铺BGM。

FPV的核心是第一人称视角的速度感和空间感。镜头语言是主差异点：俯冲、环绕、穿缝、贴面、追逐、揭示。主体和场景服务于运镜，不是运镜服务于台词。

FPV的“穿越/跃迁”必须落到具体洞口、缝隙、隧道、岩壁转折或空间层次切换。提示词必须写清穿越前的现实锚点、穿越物、穿越后的空间规则、主体或目的地变化；往事闪回线也要写清闪回触发物和回到现实的切换。

## 人物追踪+往事反差模板

当用户要求跟踪人物、带入生活往事、切入痛点反差、用视觉画面音效吸引观众时，用这一组模板。现实线保留FPV速度感，往事线用短闪回制造反差；不靠台词解释情绪。

### 现实追踪线

```text
【豆包 Seedance 2.0】
[主体动作] 无人机从高处俯冲后锁定[人物]，保持1-2米贴身追踪；重点拍背影、侧身、肩膀起伏、脚步落地、手部抓握和衣料被风压动。
[场景环境] 清晨山地、峡谷小径、溪谷、碎石坡、林线或草甸；人物与地形保持同一季节、同一光线。
[光影氛围] 上午侧逆光或云隙光，山林冷青绿，高光暖白；人物轮廓清晰。
[镜头语言] FPV追人，距离不脱；画面边缘轻微广角畸变，速度感由前景树干、碎石和水花产生。
[视觉风格与画质] 8K，高帧率，自然速度模糊，高动态范围。
[约束] 9:16或16:9，无字幕水印，人物服装一致，不拍清晰正脸。

【豆包 Seedance 2.5】
可按时间块直出：0-3秒俯冲锁人，4-10秒贴身追人，11-20秒穿越地形，21-30秒减速揭示。人物特征、服装、泥点和道具在每段重复声明。

【MiniMax Hailuo 3】
模式：T2VA或Ref2VA。
[0-3s] FPV俯冲，前景物体快速掠过，人物背影进入画面中心。
[3-8s] 侧后方1-2米追踪，脚步、呼吸和衣料反应成为节奏核心。
[8-12s] 穿过地形障碍，人物保持清晰，背景速度模糊。
overall_soundscape: 风噪、脚步、碎石、呼吸和溪水；音量随距离变化。
non_diegetic_music: 低频心跳与紧凑鼓点，120-132 BPM，节拍跟随脚步。
```

### 生活往事闪回线

```text
【豆包 Seedance 2.0】
[主体动作] [人物]停顿或静止，只保留一个具体痛点动作：看手机、吃冷掉的外卖、握着电脑包、把钥匙停在锁孔前、双手撑膝呼吸。
[场景环境] 雨夜办公室、地铁站玻璃、旧楼道、出租屋门口或深夜街头；空间小、层次少、有生活痕迹。
[光影氛围] 低照度冷青蓝或冷黄绿光，窗外城市光斑，画面边缘轻微暗角。
[镜头语言] 固定机位或缓慢推近，距离比现实线更近，画面更静。
[视觉风格与画质] 8K，低饱和，轻微颗粒感。
[约束] 0.6-2秒短闪回，不做完整叙事，不拍清晰正脸，无字幕水印。

【豆包 Seedance 2.5】
用0.6-2秒插入，不超过两处；每处只保留一个动作、一个道具和一个声音点。可用图片参考锁定旧空间或人物服装。

【MiniMax Hailuo 3】
模式：T2VA或I2VA。
[0-1s] 雨滴糊住玻璃，城市灯光散开，人物的手或侧影进入画面。
[1-2s] 钥匙停在锁孔前，灯管轻闪，人物肩膀下压后回到现实。
overall_soundscape: 雨声、键盘、地铁关门、楼道灯嗡鸣或钥匙金属声；声音比现实段更闷。
non_diegetic_music: 低频垫或短暂抽空；第1秒轻压，第2秒硬切回现实鼓点。
```

## FPV

### 开头镜头模板（前3秒钩子）

```text
【豆包 Seedance 2.0】
[主体动作] 无人机从[场景]边缘加速俯冲，第一视角下前景物体快速掠过，速度感由视觉流场和风噪传达。
[场景环境] 城市楼群缝隙、峡谷岩壁、隧道入口或桥梁下方，有明确的穿越目标。
[光影氛围] 自然硬光或霓虹点光，穿越瞬间明暗交替。
[镜头语言] 第一人称POV，俯冲加速，画面边缘轻微畸变，无稳定器痕迹。
[视觉风格与画质] 8K，高帧率，广角FOV 120-140度，暗角轻微。
[约束] 9:16或16:9，3-5秒，无字幕水印，保持视角连续。

【豆包 Seedance 2.5】
若做30秒直出，0-3秒俯冲钩子，4-10秒贴面穿越，11-20秒空间揭示，21-30秒减速收束。可用建筑外观、地形、入口首帧控制穿越起点。

【MiniMax Hailuo 3】
模式：T2VA或I2VA。
[0-2s] POV俯冲，前景结构快速放大，速度线由周围物体产生。
[2-5s] 穿过缝隙或洞口，画面亮度从暗到亮切换。
overall_soundscape: 风噪主导，穿越瞬间短促气压变化。
non_diegetic_music: 电子低频垫，120-140 BPM，鼓点与穿越同步。
```

### 中段叙事模板（贴面穿越/追逐）

```text
【豆包 Seedance 2.0】
[主体动作] 无人机贴着[场景]表面高速掠过，或跟随一辆[交通工具]，距离保持1-2米不脱。
[场景环境] 城市天台边缘、林间小径、废弃厂房、隧道内部或水面低空。
[光影氛围] 侧逆光或隧道口逆光，表面纹理在掠过时清晰可见。
[镜头语言] POV贴面飞行或追逐跟拍，画面有速度模糊但主体清晰。
[视觉风格与画质] 8K，高帧率，动态模糊自然。
[约束] 场景连贯，视角不跳切，无字幕水印。

【豆包 Seedance 2.5】
用5-8秒时间块串联不同段落；每块只留一个穿越或追逐目标。可用多段参考素材分别控制空间外观和运动方式。

【MiniMax Hailuo 3】
模式：Ref2VA或T2VA。
[0-3s] POV贴近岩壁或建筑表面，纹理和阴影快速流动。
[3-6s] 摇镜或转向，进入下一个空间层次。
overall_soundscape: 风噪、材质摩擦、引擎/脚步跟随。
non_diegetic_music: 电子打击乐，130 BPM，节奏与转向同步。
```

### 高潮/情绪峰值模板（空间揭示/环绕）

```text
【豆包 Seedance 2.0】
[主体动作] 无人机从狭窄空间穿出后突然减速或拉远，[场景]全貌在第一视角下展开；或围绕[主体]做360度环绕。
[场景环境] 峡谷开口、城市天台、教堂穹顶内部、山脊尽头的开阔地。
[光影氛围] 黄金时刻逆光或洞穴出口强光，轮廓清晰。
[镜头语言] POV穿出后急停，或环绕主体做完整圆周运动。
[视觉风格与画质] 8K，高动态范围，广角保持沉浸感。
[约束] 空间展开不拼接，环绕轨迹连续。

【豆包 Seedance 2.5】
可直出8-15秒：1-4秒穿越，5-8秒急停揭示，9-15秒环绕。用首尾帧控制穿越出口和环绕起点。

【MiniMax Hailuo 3】
模式：FL2VA或Ref2VA。
[0-3s] POV穿越窄缝或隧道。
[3-7s] 穿出后急停，全景在第一视角下展开。
[7-10s] 环绕[主体]或标志物，背景随旋转流动。
overall_soundscape: 风噪从高速骤降为低速，环境声进入。
non_diegetic_music: 弦乐或合成器长音，70 BPM，第4秒进入。
```

### 结尾收束模板

```text
【豆包 Seedance 2.0】
[主体动作] 无人机从高速减速到悬停或缓慢后退，[场景]最后画面定格在远景或主体剪影。
[场景环境] 与前段同一空间，视角拉到能看到全貌的位置。
[光影氛围] 保持前段光源，不跳变。
[镜头语言] POV减速后退或缓慢拉远，画面稳定。
[视觉风格与画质] 8K，色彩与前段一致。
[约束] 留标题安全区，无字幕水印。

【豆包 Seedance 2.5】
结尾延长到6-10秒，从减速到定格。可用前一场景尾帧延长。

【MiniMax Hailuo 3】
模式：L2VA或T2VA。
[0-3s] POV减速，速度线和风噪减弱。
[3-6s] 缓慢后退或拉远，画面定格在全景或剪影。
overall_soundscape: 远风、环境余响。
non_diegetic_music: 合成器长音，64 BPM，第5秒淡出。
```
