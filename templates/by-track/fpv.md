# FPV提示词模板

先读取 [../../references/track-core.md](../../references/track-core.md) 和 [../../references/tracks/fpv.md](../../references/tracks/fpv.md)。提示词按 `模型=` 从 [../../references/model-seedance.md](../../references/model-seedance.md) 或 [../../references/model-hailuo.md](../../references/model-hailuo.md) 加载对应结构。

人物追踪往事反差模式按 [../../references/video-pipeline.md](../../references/video-pipeline.md) 执行：现实动作线、生活往事闪回、痛点反差、声音驱动共同推进；无人机/POV追踪人物。

## 四段骨架

### 入口

```text
[固定叙事链] 现实压力锚点=[人物处境]；幻想种子=[穿越后的空间预期]；触发物穿越=门洞/窗口/洞穴/桥洞/隧道/镜面。
[主体动作] [主角]进入[入口空间]，视线锁定穿越目标。
[场景环境] 有纵深和空气密度的真实空间。
[镜头语言] 第一视角或无人机跟随，速度变化有原因。
[约束] 9:16或16:9，[时长]，人物一致。
```

### 穿越

```text
[固定叙事链] 微缩奇观=穿越后的规则与景观变化。
[主体动作] [主角]完成[连续飞越/跑动动作]。
[场景环境] 前景遮挡、瓶颈、落差或转角制造速度感。
[镜头语言] 穿越前后保持连续运动，不硬切。
[约束] 运动轨迹可拍摄，空间结构不重复拼接。
```

### 往事反差

```text
[固定叙事链] 幻想种子转入[往事画面]；动作证明=现实与回忆的对照。
[主体动作] [主角]在[现实动作]中看到[往事物件/影子/光线]。
[镜头语言] 现实线用快速POV，往事线用更慢的柔焦跟随。
[音效] 环境声收窄，往事声浮出，再被现实声压回。
```

### 收口

```text
[固定叙事链] 现实回声=[身体或生活状态变化]；收口=停在可回忆的物证或出口。
[主体动作] [主角]在[出口/高点/地面]完成[情绪收束]。
[镜头语言] 从环绕或俯冲收为稳定中景。
[约束] 保持人物与道具连续。
```
