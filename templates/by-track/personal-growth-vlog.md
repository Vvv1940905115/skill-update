# 个人成长Vlog提示词模板

生成前先读取 [../../references/track-core.md](../../references/track-core.md) 和 [../../references/tracks/personal-growth-vlog.md](../../references/tracks/personal-growth-vlog.md)，按参考稿结构输出选题、角色、镜头、提示词和发布信息。

强制套用固定叙事链：现实压力锚点 -> 幻想种子 -> 微缩奇观 -> 触发物穿越 -> 主体登场 -> 动作证明 -> 收口 -> 现实回声。每个模型提示词写清`[固定叙事链]`和`[人物连续性]`；人物微表情跟随情绪变化，音效按叙事节点分层递进，禁止平铺BGM。

个人成长片的“穿越/跃迁”通常是便签、日历、门把、钥匙、闹钟、旧记录本或决定性动作把现状推入方法场或回忆场。提示词必须写清现状证据、触发物、时间/光线规则变化和主体转变。

## 个人成长Vlog

### 开头镜头模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]把写满计划的便签墙拍下来，随后撕掉其中一张，指节因用力发白。
[场景环境] 清晨出租屋墙面，桌上是冷水杯、手机和没吃完的吐司。
[光影氛围] 百叶窗切成条状硬光，尘埃在光带中浮动。
[镜头语言] 中近景固定，先拍手，再缓慢推到眼神。
[视觉风格与画质] 写实生活感，胶片颗粒，自然色彩，8K。
[约束] 9:16或16:9，3-5秒，无字幕水印。

【豆包 Seedance 2.5】
2.5可用单段30秒做"失败瞬间-决定-第一天尝试"的开篇结构；在0-5秒保留撕便签的动作钩子，后续只递进一个变化。

【MiniMax Hailuo 3】
模式：T2VA或I2VA。
[0-2s] 特写，手指捏住便签边缘，纸面有涂改痕迹。
[2-5s] 撕纸声后切中近景，眼神不看镜头，喉结轻微滚动。
overall_soundscape: 时钟秒针、纸撕开、窗外远处车声。
negative: 模糊，肢体畸变，多余手指，水印，字幕。
```

### 中段叙事模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]在桌面摆出三本记录本，右手逐本翻开，左手把手机扣在桌面上。
[场景环境] 深夜书房，台灯光圈只照亮摊开的页面和手腕。
[光影氛围] 暖白台灯与冷蓝夜窗对比，背景压暗。
[镜头语言] 俯拍接平视，先用俯拍展示记录变化，再用平视拍疲惫表情。
[视觉风格与画质] 写实纪录感，自然颗粒，8K。
[约束] 页面文字无乱码，人物与房间一致。

【豆包 Seedance 2.5】
用[0-6s]记录、[7-12s]失败、[13-18s]调整三段时间块；可给房间、人物、道具添加参考素材，并指定服装与台灯状态不变。

【MiniMax Hailuo 3】
模式：T2VA或Ref2VA。
[0-3s] 俯拍，手指沿日历格子划过，铅笔圈出两次中断。
[3-6s] 中景，[主角]深呼吸后合上本子。
[6-9s] 平视，手重新拿起笔，笔尖落在空白格。
overall_soundscape: 纸页、铅笔摩擦、呼吸。
non_diegetic_music: 极简钢琴，60 BPM，低音量。
```

### 高潮/情绪峰值模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]完成[核心动作]后停在原地，双手下垂又慢慢握拳，眼眶泛红但不哭出声。
[场景环境] 空旷训练场、舞台边缘或清晨街道，地面上有长影子。
[光影氛围] 侧逆光勾出肩线，地面积光形成微弱反射。
[镜头语言] 手持缓慢推近，从脚部沿身体上升到面部。
[视觉风格与画质] 写实纪录感，高动态范围，8K。
[约束] 情绪只通过动作外化，不使用字幕水印。

【豆包 Seedance 2.5】
可延长成10-15秒：先给失败重复，再给最后一次成功。2.5用参考素材保持服装、汗渍、场景光源连续。

【MiniMax Hailuo 3】
模式：T2VA或FL2VA。
[0-3s] 手部特写，指尖颤抖，掌心压在地面上。
[3-6s] 中景，[主角]起身，重心从右腿移到双腿。
[6-10s] 缓慢推近，呼吸变慢，眼神从躲闪转为直视前方。
overall_soundscape: 呼吸、布料摩擦、远处环境低频。
non_diegetic_music: 无节拍弦乐，单音在第6秒抬升，78 BPM以内。
```

### 结尾收束模板

```text
【豆包 Seedance 2.0】
[主体动作] [主角]把今天的记录本合上，在封皮写下日期，然后把笔帽轻轻按上。
[场景环境] 桌面整洁，只留记录本、笔、一杯水。
[光影氛围] 夜晚台灯稳定暖光，四周渐暗。
[镜头语言] 固定中近景，最后一次轻微推近。
[视觉风格与画质] 写实生活感，胶片颗粒，8K。
[约束] 人物一致，无字幕水印。

【豆包 Seedance 2.5】
若做阶段复盘，用最后5-8秒加入"第1天/第30天"两个画面对照，但保持机位和服装位置一致。

【MiniMax Hailuo 3】
模式：T2VA或L2VA。
[0-3s] 特写，笔帽按下，台灯轻微反光。
[3-6s] 缓慢拉远，[主角]双手交叠在桌沿。
[6-8s] 画面停在记录本封皮和手部。
overall_soundscape: 笔帽、纸张、时钟。
non_diegetic_music: 钢琴单音，60 BPM，第6秒淡出。
```
