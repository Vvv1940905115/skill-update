# 旅行Vlog提示词模板

先读取 [../../references/track-core.md](../../references/track-core.md) 和 [../../references/tracks/travel-vlog.md](../../references/tracks/travel-vlog.md)。提示词按 `模型=` 从 [../../references/model-seedance.md](../../references/model-seedance.md) 或 [../../references/model-hailuo.md](../../references/model-hailuo.md) 加载对应结构。

固定叙事链逐节点映射；旅行片的“穿越/跃迁”通常是登机口、检票口、车窗、隧道出口、地图折痕或天气变化。必须写清穿越前后的光线、空间规则和人物状态变化。

## 四段骨架

### 开头

```text
[固定叙事链] 现实压力锚点=赶路/预算约束；幻想种子=目的地预期；微缩奇观=首见景观或烟火气；触发物穿越=登机口/检票口/车窗/隧道出口。
[主体动作] [主角]从[出发状态]进入[目的地首场景]，手部与眼神给出具体反应。
[场景环境] [城市/景点/交通空间]，保留可触细节。
[光影氛围] [时间光源]，人物和景深都可拍摄。
[镜头语言] [景别/机位/运动原因]。
[约束] 9:16或16:9，[时长]，人物一致，无字幕水印。
```

### 中段

```text
[固定叙事链] 动作证明=路线选择、与本地人互动、食物或交通体验。
[主体动作] [主角]完成[核心体验动作]，微动作跟随情绪。
[场景环境] 保留路线纵深与当地物证。
[镜头语言] 中景交代空间，近景承接反应。
[约束] 保持人物、服装、场景一致。
```

### 高潮

```text
[固定叙事链] 微缩奇观峰值=目的地高点、开阔纵深或氛围反转。
[主体动作] [主角]在[高点/反差场景]完成[情绪动作]。
[镜头语言] 从人物升到空间或从空间压回人物。
[约束] 风景不重复拼接，人物不变形。
```

### 结尾

```text
[固定叙事链] 现实回声=返程、下一站预告或生活变化。
[主体动作] [主角]完成[收束动作]。
[镜头语言] 中近景收束，留白可加花字。
[约束] 与前后光线和服装连续。
```
